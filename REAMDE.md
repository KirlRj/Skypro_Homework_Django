## Описание:

Проект "Выполнение домашней работы по курсу Python - разработчик, модуль Django" - это выполнение домашних задач по модулю 6 "Основы Django"

На текущий момент в проекте есть следующая функциональность:
1) Добавлена вкладка "Домашняя" и "Контакты".
2) На вкладке "Контакты" есть заполнение данных для обратной связи.
3) Добавлено подключение к БД
4) Созданы категории и продукты в Бд с помощью Shell, фикстур, кастомной команды
5) Создана админка и выполнена настройка страницы админа
